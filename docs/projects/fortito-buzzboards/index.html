FortiTo’s BuzzBoards™ educational technology system is based on a series of pluggable hardware and software modules, which can be assembled in different combinations, determining both the functionality and physical form, to create a variety of electronic prototypes.

These drivers (developed in Python) use the I2C protocol to add sensors and actuators to a Raspberry Pi through a hub base board (BuzzBerry).

Overview & Architecture

The BuzzBoards ecosystem provides an accessible pathway for students and researchers to build intelligent computing prototypes:

  • Modular Hardware: Stackable boards allowing rapid connection of sensors, displays, and actuators without complex breadboard wiring.
  • Python Drivers: Lightweight, robust library implementing the I2C protocol for seamless hardware interaction.
  • Raspberry Pi Integration: Designed around the Raspberry Pi and BuzzBerry hub board, supporting diverse educational workshops and IoT prototyping projects.

Source code and driver libraries are openly available on GitHub.
